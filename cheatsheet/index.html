TWO ARCHITECTURES · HEAD TO HEADWhat I trained and why

A · B
ABaseline CNN — built from scratch (won ★)›
One-liner: “Three conv blocks, global average pooling, sigmoid head. Roughly 100K parameters — fits on a phone.”
Block 1 · Conv 32 + BN + Pool
Captures low-level edges and stain boundaries.
Block 2 · Conv 64 + BN + Pool
Mid-level — cell shapes, texture clusters.
Block 3 · Conv 128 + BN + Pool
Higher-level — parasite-like blobs / vacuoles.
Head · GAP → Dropout → Dense 64 → Sigmoid
Compresses spatial map to a single probability.
  • ✅ Trains in ~12 min on Colab T4.
  • ✅ Won the head-to-head — 95.50% test accuracy.
  • ⚠️ Small capacity — would saturate on harder, larger benchmarks.
BResNet50 transfer learning›
One-liner: “ImageNet pretrained ResNet50, frozen base, fresh classifier head. Two-stage training — head-only, then unfreeze the last block at lr=1e-5.”
Stage 1 · frozen base
8 epochs · base weights frozen · only head trained.
Stage 2 · fine-tune last block
5 epochs · last block unfrozen · lr=1e-5 to avoid wrecking ImageNet features.
Head · GAP → Dropout → Dense 128 → Sigmoid
Larger head than baseline to absorb 2048-dim ResNet features.
  • ⚠️ Lost the head-to-head: 94.53% acc · ~1 point behind on every metric.
  • ⚠️ Trains slower — ~31 min total on Colab T4.
  • ✅ Still useful as a sanity-check baseline; demonstrates the “transfer doesn’t always help” lesson.

VIVA Q&A · FALLBACK LINESIf asked …, say …

Why this dataset?
NIH Malaria Cell Images — the standard benchmark cited in most papers. 27,558 thin-smear cell crops, 50/50 balanced, openly licensed on Kaggle. Lets the result be compared apples-to-apples with published work.
Why two models — wasn’t one enough?
The brief says advanced CNN. I read that as “show comparison reasoning.” Baseline CNN proves the task is tractable from scratch; ResNet50 tests whether transfer learning helps. The contrast is the interesting finding.
Why did the small CNN beat ResNet50?
ImageNet’s inductive bias is natural-scene photos — colour palette, lighting, foreground geometry. Microscopy is none of those. Transfer learning hurts more than it helps when source and target domains disagree this much. The custom CNN learns task-specific filters from scratch with no prior baggage.
How did you handle class imbalance?
The dataset is already 50/50 balanced — I verified in the EDA notebook. So I used a stratified 70/15/15 split + reported per-class F1 instead of leaning on weighted loss. The class-weighted-loss code is there as defensive scaffolding, but it’s not load-bearing.
What about image noise and variability?
Augmentation pipeline runs on every training sample: Gaussian noise σ=0.02, horizontal + vertical flips, rotation ±20°, brightness ±15%, contrast ±15%. This directly addresses both requirements in the brief.
How does Grad-CAM work?
It computes gradients of the prediction with respect to the activations of the last convolutional layer. The gradients are pooled into per-channel weights, then combined with the activations to produce a heatmap. Red = pixels that drove the decision. For parasitized cells, hot zones should overlap parasite blobs — gives clinicians a sanity check.
Where would you set the decision threshold?
0.5 in my report. For real-world malaria screening you’d lower it to roughly 0.3 — missing a parasitized cell is clinically much worse than a false alarm. The ROC curve in reports/figures/ shows the trade-off.
What’s reproducible — and what’s the limit?
Fully reproducible: all hyperparams in config.yaml, fixed random seed, single Colab notebook trains end-to-end. Limit: the model is trained on segmented single-cell crops. To run on whole-slide thin-smear images you’d need to add a cell-detection front-end first.
If you don’t know the answer
“That’s exactly one of the future-work items I flagged in the README — I don’t have a clean answer yet, which is why it’s on the next-steps list.” Honest, points to a real document, ends politely.
