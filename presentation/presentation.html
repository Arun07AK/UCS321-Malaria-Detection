Two Architectures Compared

Baseline CNN

~100K parameters

  • 3 × (Conv2D 3×3 + BatchNorm + MaxPool)
  • 32 → 64 → 128 filters
  • GlobalAveragePooling2D
  • Dense 64 → Dropout → Sigmoid

Fast trains in minutes on CPU

ResNet50 Transfer

~24M parameters

  • ResNet50 base (ImageNet weights, frozen)
  • GlobalAveragePooling2D
  • Dense 128 → Dropout → Sigmoid
  • Two-stage: frozen → fine-tune top block

Accurate ImageNet inductive bias

Grad-CAM — Why the model decides

What it does

Highlights which pixels contributed most to the prediction. For Parasitized samples, the model should focus on parasite-shaped artifacts inside the cell.

Why it matters

Medical experts cannot trust a black box. Grad-CAM gives them a visual hand-off — "the model saw this region; here's why."

Generated views

  • 4×4 grid — True Positives (correct parasite calls)
  • 4×4 grid — True Negatives (correct healthy calls)
  • 4×4 grid — False Positives (review with experts)
  • 4×4 grid — False Negatives (most clinically dangerous — investigate)
