The Problem  ·  Statement #4 (Biocon Ltd.)
Brief. Develop an advanced CNN model to classify red blood cell images as healthy or malaria-infected — addressing class imbalance, image noise, and variability — while incorporating Grad-CAM interpretability to assist medical experts in validating predictions.

Advanced CNN

Gaussian noise augmentation

Baseline CNN — built from scratch

~100K paramsTrains in 12 min
1Block 1Conv 32 → BN → MaxPool
2Block 2Conv 64 → BN → MaxPool
3Block 3Conv 128 → BN → MaxPool
4HeadGAP → Dropout → Dense 64 → Sigmoid

ResNet50 — transfer learning

~24M paramsTrains in 31 min
1BaseResNet50 · ImageNet weights
2Stage 1Frozen base · train head only
3Stage 2Unfreeze last block · fine-tune at 1e-5
4HeadGAP → Dropout → Dense 128 → Sigmoid
Both share the same loss + callbacks. Adam optimizer · binary cross-entropy · EarlyStopping on val_AUC · ReduceLROnPlateau · ModelCheckpoint.

Reflections  &  thanks

✓ What worked

95.5% test accuracy with a tiny custom CNN. End-to-end reproducible pipeline — config + scripts + Colab notebook. Grad-CAM grids satisfy the interpretability brief.

⚡ What surprised

A 100K-param baseline beat ResNet50 (24M params) head-to-head. ImageNet bias hurts when target images are far from natural-scene photos.

→ What's next

Whole-slide rather than per-cell. Calibration for clinical thresholds. Test-time augmentation for confidence intervals.
